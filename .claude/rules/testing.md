# 테스트 규칙

- 실행: `backend` 에서 `uv run pytest`. 백엔드를 고쳤으면 커밋 전에 돌려 결과를 보고하고, 실패하면 커밋하지 않는다.
- LLM·TTS 는 테스트에서 실제로 부르지 않는다. `tests/conftest.py` 의 `FakeLLM`(응답 목록을 차례로 돌려주고 `LLMError` 항목은 예외로 던짐)을 쓴다.
  - 왜: 무료 한도가 작고, 테스트가 네트워크·키 상태에 따라 흔들리면 안 된다.
- 테스트에 `.env` 값이 새어 들어오지 않게 한다. `Settings()` 는 실행 위치의 `.env` 를 읽으므로 테스트에서 인자 없이 만들지 않는다. 필요하면 값을 인자로 직접 넣는다.
- 테스트 카드는 토끼·장미·별, 선택지는 `CHOICE_SETS` 처럼 카드와 겹치지 않게 만든다.
  - 왜: v2 부터 이미 나온 것·카드는 선택지에 다시 쓰면 검증 실패한다.
- 프롬프트 버전 규칙을 추가하면 `test_prompt_vN.py` 를 따로 만든다(이전 버전 테스트는 그대로 둔다).
