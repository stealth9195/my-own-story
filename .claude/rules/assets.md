# 그림 에셋·장면 조립 규칙

## 제작
- ComfyUI + FLUX.1 schnell 로컬 생성(steps 4, cfg 1.0, euler/simple). 프롬프트는 `assets/image-prompts.html`(복사 버튼, 영어).
- 그림체: 얇은 테두리 + 크레용·색연필 질감. 공통 스타일 문구는 모든 프롬프트에 같게 붙인다.
  - 왜: 굵은/얇은 테두리를 같은 seed 로 비교했더니 차이가 거의 없어 얇은 쪽으로 정함(2026-10-29).
- 원본은 `assets/raw/<카탈로그 id>.png`. 파일 이름이 카탈로그 id 와 같아야 앱에서 바로 연결된다.
- 크기: 캐릭터·사물 1024×1024(흰 배경 → 나중에 `rembg` 로 배경 제거 → WebP), 배경 1344×768(16:9).
- 같은 프롬프트라도 seed 마다 결과가 다르다. 사람이 한 장씩 보고 고른다.
  - 실제로 겪은 실패: 토끼 눈 없음·귀 하나, 용 꼬리 둘, 고양이 꼬리 둘. 눈·귀·꼬리·다리 개수와 그림 속 글자를 확인한다.
  - 프롬프트에 개수를 적는다("two ears", "one tail"). 작은 군더더기는 흰색으로 칠하거나 인페인팅으로 지운다.
- 라이선스 있는 참고 그림은 분위기만 참고하고, 생성 입력(img2img 등)으로 쓰지 않는다.

## 배경·시간대
- 시간대(낮·밤·노을)는 따로 그리지 않고 CSS 색 덮기로 표현한다(밤: 남색, 노을: 주황, 둘 다 multiply). 배경 그림의 밝기·채도도 함께 조절하고, 캐릭터에는 덮지 않는다.
  - 노을을 soft-light 로 했더니 밝은 배경에서 노란빛만 돌아 multiply 로 바꿨다(2026-10-30).
  - 그래서 배경에 해·달을 그리지 않는다. 필요하면 달·별은 사물 그림을 얹는다.
- 배경은 아래쪽에 캐릭터를 세울 빈 바닥을 두고, 중요한 것은 가운데 4:3 영역에 둔다(4:3 태블릿에서는 `object-fit: cover` 로 좌우가 잘림).
- 화면은 가로가 기본. 세로일 때는 위에 16:9 장면 상자, 아래에 글·선택지를 둔다(`@media (orientation: portrait)`).

## 상태 표현
- 상태(states)별로 캐릭터를 따로 그리지 않는다. 캐릭터는 한 장이고, 상태는 **CSS 움직임 + 머리 옆 효과 그림 1장**으로 표현한다.
  - idle·walking: 움직임만. talking `…`, sleeping `Zzz`, happy 반짝 선, surprised `!`(발견도 이것), scared 땀방울, thinking `?`.
  - 효과 그림을 SVG 로 직접 만들지 생성할지는 아직 정하지 않았다.

## 바라보는 방향 (좌우 반전)
- 카탈로그의 캐릭터마다 `facing`(`left` | `right` | `front`)을 적는다. 그림을 저장할 때 눈으로 보고 적는다.
  - 왜: 프롬프트에 "facing right"를 넣어도 실제 결과는 제각각이었다(토끼는 왼쪽, 고양이는 거의 정면).
- 방향은 놓이는 자리로 정한다. 화면 왼쪽 캐릭터는 오른쪽을, 오른쪽 캐릭터는 왼쪽을 본다(서로 마주 봄).
  - 먼저 순서를 정한다: 오른쪽을 보는 캐릭터 → 정면 → 왼쪽을 보는 캐릭터 순으로 왼쪽부터 세운다(`scene.ts` 의 `arrangeActors`). 그래서 뒤집기는 같은 방향이 둘 이상일 때만 일어난다.
  - 그래도 원하는 방향과 `facing` 이 다르면 `transform: scaleX(-1)` 로 표시할 때만 뒤집는다. `front`·가운데 자리는 뒤집지 않는다. 파일은 미리 뒤집어 두지 않는다.
  - `front` 와 아직 안 적은 값(`""`)은 어느 자리에 서도 된다. 사물은 캐릭터 뒤(오른쪽)에 둔다.
- 효과 그림(`?`, `Zzz` 등)은 뒤집는 요소 **바깥**에 붙인다. 안에 넣으면 글자가 거울처럼 뒤집힌다. 위치는 바라보는 쪽 머리 위.
