에셋 이미지 프롬프트

'복사'를 누르면 대상 문구와 스타일 문구가 합쳐진 전체 프롬프트가 복사됩니다. '완료' 체크는 이 브라우저에만 저장됩니다.

생성 설정
steps / cfg4 / 1.0
sampler / schedulereuler / simple
크기캐릭터·사물 1024 × 1024, 배경 1344 × 768
저장 파일 이름각 항목의 id 그대로 (예: bear.png)
생성 팁
  • 같은 프롬프트인데 결과가 매번 다른 건 seed 가 매번 바뀌어서입니다(KSampler 의 control after generate 가 randomize). 마음에 드는 그림이 나오면 그때 seed 를 적어 두면 같은 그림을 다시 만들 수 있습니다.
  • Empty Latent Image 의 batch_size 를 3~4로 두면 한 번에 여러 장이 나와서 고르기 편합니다.
  • 잘 틀리는 곳: 눈 개수, 귀 개수, 꼬리 개수, 다리 개수, 그림 속 글자. 저장 전에 이것만 확인하세요.
  • 이미 저장한 그림: 토끼(rabbit), 아기 용(dragon), 풀밭(meadow). 아래 목록에서 '완료'로 표시해 두었습니다.
